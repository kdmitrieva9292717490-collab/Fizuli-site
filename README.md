# Fizuli — вёрстка интернет-магазина (прототип для передачи в разработку)

Статичная вёрстка редизайна сайта fizuli.ru: 23 HTML-страницы, один `style.css`, один `script.js`. Сборки и зависимостей нет.
Это эталон вёрстки для переноса на боевую платформу: размеры, цвета, отступы и поведение берутся из кода. Товары, оплата, вход и корзина — демо-заглушки без сервера.

- Живой прототип: https://kdmitrieva9292717490-collab.github.io/Fizuli-site/
- Репозиторий: https://github.com/kdmitrieva9292717490-collab/Fizuli-site
- Дизайн: файл Figma «Редизайн интернет-магазина Fizuli (Copy)», страница «Презентация для Физули». **Источник правды — этот код, Figma местами устарел** (см. раздел «Расхождения с Figma»).

## Как запустить

Скачать архив (Code → Download ZIP) или `git clone`, затем открыть `index.html` или поднять любой статический сервер в папке:

```
python -m http.server 5500
```

Без сервера (двойной клик) часть страниц тоже открывается, но фильтры по ссылкам (`?category=`, `?collection=`) надёжнее проверять через сервер.

Параметр `?v=число` у `style.css` и `script.js` нужен только для сброса кэша на GitHub Pages; на боевой платформе не нужен.

## Три версии по ширине

| Версия | Ширина | Как устроен CSS |
|---|---|---|
| Десктоп | от 1024px | базовые стили + блоки `@media (min-width: 1024px)` |
| Планшет | 768–1023px | блоки `@media (min-width: 768px) and (max-width: 1023px)` |
| Мобильная | до 767px | блоки `@media (max-width: 767px)` |

Планшет — это **мобильная логика с планшетными числами** (мобильные шапка, меню, футер, карточки, фильтры), а не сжатый десктоп. Блоки в `style.css` идут по принципу «поздний перебивает ранний» — порядок правил важен, не сортировать файл. Самые свежие правки лежат в конце файла.

## Система отступов

Все значения — px, между краями блоков.

**Десктоп**

| Что | Значение |
|---|---|
| Хедер → хлебные крошки | 40 |
| Крошки → заголовок | 16 |
| Заголовок → фильтры | 32 |
| Фильтры → первый ряд карточек | 20 |
| Между карточками / между рядами | 16 / 40 |
| Карточек в ряду | 4 |
| Сетка → «Смотреть ещё» | 60 |
| Между блоками и до футера | 120 |
| Страница товара: крошки → фото | 32 |

**Планшет**

| Что | Значение |
|---|---|
| Хедер → хлебные крошки | 40 |
| Крошки → заголовок | 0 (зона клика крошек уже 40) |
| Заголовок → фильтры / вкладки / контент | 24 |
| Фильтры / вкладки → контент | 16 |
| Между карточками / между рядами | 12 / 32 |
| Карточек в ряду | 4 (по 171px) |
| Между блоками и до футера | 80 |

**Мобильная**

| Что | Значение |
|---|---|
| Крошки → заголовок | 0 |
| Фильтры → карточки | 12 |
| Между карточками / между рядами | 8 / 20 |
| Карточек в ряду | 2 |
| Между блоками и до футера | 60 |

**Безопасные зоны клика (планшет и мобильная):** высота крошек, вкладок, навигационных ссылок и кнопок — 40px. Иногда зона невидимая (`::before`), чтобы не двигать подчёркивание.

## Токены

Цвета — CSS-переменные в `:root` (начало `style.css`), названия совпадают с переменными Figma (`--text-black`, `--stroke-black-10`, `--bg-gray1` и т. д.). Полупрозрачные серые линии, которые накладываются друг на друга, заменены непрозрачным #E7E7E7 (прогресс-бар доставки).

Шрифты:
- `--font-body`: Golos Text (Google Fonts), основной текст.
- `--font-display`: TT Supermolot Neue, заголовки и цены. **В репозитории лежит триальная версия (`TT Supermolot Neue Trial`, файлы `assets/fonts/tt-supermolot-neue`). После покупки лицензии заменить файлы и имя `font-family` в `style.css` (`:root` и два блока `@font-face`).**

Межстрочный интервал: основной текст 140%; у названий товаров, способов оплаты и абзацев на «Партнёрам»/«Магазины» — Auto (осознанно).

## Каталог, коллекции и фильтры

- Меню и ссылки ведут на каталог с предвыбором: `?category=футболки`, `?collection=patchi`. Скрипт (`script.js`, начало файла) прячет остальные карточки через атрибут `hidden`.
- Товар принадлежит коллекции через атрибут `data-collection` на карточке; категории — `data-category`. Коллекции: HYBRID ATHLETIC CLUB, PATCHI, SENSEI (SENSEI только в мужском меню и фильтрах). Демо-карточки коллекций есть только в `men.html` (фото в `assets/images/Huracan`, `assets/images/Patchi`). У «Сенсей» пока нет товаров — при выборе показывается весь каталог.
- Карточки всех страниц каталога раскладываются **одной общей сеткой** (`.catalog-grid-rows`), обёртки-ряды `.catalog-grid-row` прозрачные (`display: contents`): лишние карточки сами переносятся на следующий ряд.
- Видео-карточка (только десктоп): если видимых товарных карточек 7 и больше — стоит на 8-м месте, если меньше — убирается из каталога.
- Плашки размеров (карточки, окно «Выберите размеры», фильтры): при 5 и более размерах растягиваются на всю ширину без промежутков, при меньшем числе — по содержимому.

**Что нужно реализовать в разработке (в прототипе не работает):** динамические фильтры. При выборе любого значения (коллекция, категория, цвет, размер, цена) в остальных группах фильтра остаются только значения, для которых есть хотя бы один товар в текущей подборке; недоступные скрываются полностью (не блокируются). Пересчёт двусторонний, по всем группам сразу. Требует, чтобы у каждого товара были заполнены все атрибуты (категория, цвет, размеры, цена, коллекция). Сейчас чекбоксы в панели фильтров только отражают выбор из ссылки.

## Что в прототипе — заглушка

- Все карточки ведут на одну страницу товара («Костюм из жатой ткани»).
- Корзина и мини-корзина считают сумму только в шторке; на странице корзины сумма и прогресс-бар статичны.
- Вход и регистрация: окно с кодом принимает любые 4 цифры, состояние хранится в `localStorage` (`fizuliLoggedIn`).
- Оформление заказа: выпадающие «город», «пункт выдачи», карта — только визуал; виджеты оплаты (Яндекс Сплит, Долями) — картинки.
- Ссылка «Сертификаты» (мегаменю, футер) — `href="#"`, страницы нет.
- Лайтбокс фото товара: лупа просто закрывает окно.
- Поиск: подсказки и популярные товары статичны.

## Расхождения с Figma (код главнее)

Макеты Figma после начала работы в коде не обновлялись. Отличия, о которых важно знать:

1. Планшетная версия переделана полностью (по системе отступов выше); в макете часть планшетных экранов старая.
2. Безопасные зоны клика 40px (крошки, вкладки, ссылки, кнопки) и высота кнопок 40px на планшете и мобильной.
3. Мегаменю на десктопе: серые заглушки вместо фото.
4. Добавлены коллекции (меню, фильтры), пункт «Сертификаты» в «Покупателям».
5. Кегли подсказок в поиске: десктоп 12px, планшет и мобильная 10px, заглавные.
6. Каталог: единая сетка, правило видео-карточки, 4 в ряд.
7. Межстрочный интервал 140% в текстах под «Ваш заказ», в событиях журнала, в заголовках пунктов оферты.
8. Различные точечные правки размеров и отступов (см. историю коммитов в GitHub).

## Открытые вопросы к бренду

1. **Шрифт TT Supermolot Neue** — в репозитории триальная версия; нужны файлы купленной лицензии.
2. **Страница «Сертификаты»** — есть ссылка в меню и футере, страницы и макета нет: нужно решение бренда, что там.
